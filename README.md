### 📖 Раздел 1. Введение в React, JSX и Props

#### Что такое React?
React — это JavaScript-библиотека для создания пользовательских интерфейсов. Главная идея React — **компонентный подход**. Интерфейс разбивается на независимые повторно используемые блоки (компоненты).

#### Синтаксис JSX
**JSX** (JavaScript XML) — расширение синтаксиса JavaScript, позволяющее писать HTML-подобный код прямо внутри JavaScript/TypeScript файлов.

```tsx
// Пример JSX элемента
const element = <h1 className="title">Привет, React!</h1>;
```

**Основные правила JSX:**
1. **Единственный корневой элемент**: Компонент должен возвращать ровно один родительский элемент. Если вам не нужен лишний тег в DOM, используйте **фрагмент** `<>` и `</>` (`React.Fragment`).
2. **Именование атрибутов в camelCase**: Вместо `class` пишется `className`, вместо `onclick` — `onClick`, вместо `for` — `htmlFor`.
3. **Вставка выражений через `{}`**: Любое JavaScript-выражение (переменная, вызов функции, математика) оборачивается в фигурные скобки.

```tsx
const name = "Алексей";
const userCard = (
  <div className="card">
    <h2>Привет, {name.toUpperCase()}!</h2>
    <p>Текущий год: {new Date().getFullYear()}</p>
  </div>
);
```

#### Что такое Props (Пропсы)?
**Props** (properties) — аргументы, передаваемые в компонент сверху от родителя к дочернему компоненту. Пропсы **доступны только для чтения (read-only)**. Изменять полученные пропсы внутри компонента запрещено.

```tsx
// Определение компонента с Props в TypeScript
interface GreetingProps {
  name: string;
  age?: number; // опциональный пропс
}

export const Greeting: React.FC<GreetingProps> = ({ name, age = 18 }) => {
  return <div>Привет, {name}! Ваш возраст: {age}</div>;
};

// Использование:
// <Greeting name="Иван" age={25} />
```

### 📖 Раздел 2. Работа со списками: `map()` и атрибут `key`

В React списки создаются с помощью стандартного метода массивов JavaScript `.map()`.

#### Атрибут `key`
При рендере списка элементов в JSX React требует указывать уникальный атрибут `key` у самого верхнего тега каждого элемента списка.

```tsx
const fruits = [
  { id: 'f1', title: 'Яблоко' },
  { id: 'f2', title: 'Банан' },
  { id: 'f3', title: 'Груша' }
];

export const FruitList = () => {
  return (
    <ul>
      {fruits.map((fruit) => (
        <li key={fruit.id}>{fruit.title}</li>
      ))}
    </ul>
  );
};
```

#### Зачем нужен `key`?
`key` помогает React определять, какие именно элементы списка были изменены, добавлены или удалены. Это критично для виртуального DOM (Reconciliation algorithm).

> [!WARNING]
> **Не используйте индекс массива в качестве `key`** (например, `key={index}`), если список может сортироваться, фильтроваться или элементы могут удаляться из середины! Это приведет к багам отображения состояния инпутов и ухудшению производительности. Всегда используйте уникальные ID объекта (`fruit.id`).

### 📖 Раздел 3. Управление состоянием: Хук `useState`

#### Что такое State (Состояние)?
В отличие от пропсов, **State** — это внутренние данные компонента, которые могут изменяться с течением времени в ответ на действия пользователя. Изменение состояния вызывает **повторный рендер (re-render)** компонента.

#### Использование `useState`
Хук `useState` принимает начальное значение состояния и возвращает кортеж из двух элементов:
1. Текущее значение состояния.
2. Функция-сеттер для обновления состояния.

```tsx
import React, { useState } from 'react';

export const Counter = () => {
  const [count, setCount] = useState<number>(0);

  const increment = () => {
    // Рекомендуемый подход обновления на основе предыдущего состояния:
    setCount((prevCount) => prevCount + 1);
  };

  return (
    <div>
      <p>Счетчик: {count}</p>
      <button onClick={increment}>+1</button>
    </div>
  );
};
```

#### Правило неизменяемости состояния (Immutability)
Никогда не мутируйте состояние напрямую (например, `state.count = 5` или `products.push(newItem)`). Всегда создавайте новый объект или массив!

```tsx
// ❌ НЕПРАВИЛЬНО:
// todos.push(newTodo);
// setTodos(todos);

// ✅ ПРАВИЛЬНО (создаем новый массив через спред-оператор):
setTodos([...todos, newTodo]);

// ✅ Обновление объекта в состоянии:
setUser((prevUser) => ({
  ...prevUser,
  age: 26 // перезаписываем только age
}));
```

#### Контролируемые компоненты (Controlled Inputs)
Политика контроля формы в React: значение инпута связывается со `state`, а событие `onChange` обновляет `state`.

```tsx
const FormExample = () => {
  const [text, setText] = useState('');

  return (
    <input
      type="text"
      value={text}
      onChange={(e) => setText(e.target.value)}
    />
  );
};
```

### 📖 Раздел 4. Побочные эффекты и жизненный цикл: Хук `useEffect`

#### Что такое Побочный эффект (Side Effect)?
Побочные эффекты — это любые действия, выходящие за рамки чистого рендеринга JSX:
- Запросы к API / серверу
- Установка таймеров (`setInterval`, `setTimeout`)
- Прямая манипуляция с DOM (например, изменение `document.title`)
- Подписка на глобальные события браузера (`window.addEventListener`)

#### Синтаксис `useEffect`
```tsx
useEffect(() => {
  // Код эффекта (выполняется после рендера)

  return () => {
    // Функция очистки (cleanup) - выполняется перед следующим запуском эффекта
    // или при размонтировании (unmount) компонента из DOM
  };
}, [dependency1, dependency2]); // Массив зависимостей
```

#### Массив зависимостей (Dependencies Array):
1. **Массив не передан** (`useEffect(() => {})`): Эффект выполняется при **каждом** рендере.
2. **Пустой массив `[]`**: Эффект выполняется **ровно один раз** при первом монтировании компонента в DOM (`componentDidMount`).
3. **Массив с переменными `[count, category]`**: Эффект выполняется при монтировании, а также **каждый раз, когда меняется хотя бы одна из указанных переменных**.

#### Функция очистки (Cleanup)
Пример предотвращения утечек памяти при работе с таймерами:

```tsx
useEffect(() => {
  const timerId = setInterval(() => {
    console.log('Тик...');
  }, 1000);

  // Очистка при размонтировании компонента
  return () => {
    clearInterval(timerId);
  };
}, []);
```

### 📖 Раздел 5. Прямой доступ к DOM и сохранение значений: Хук `useRef`

`useRef` возвращает изменяемый объект `{ current: initialValue }`, который сохраняется на протяжении всего времени жизни компонента.

#### Важнейшие особенности `useRef`:
1. Изменение `ref.current` **НЕ вызывает ререндер компонента**.
2. Используется для прямого доступа к DOM-узлам браузера (управление фокусом, скроллом, измерение размеров).
3. Используется для хранения экземпляров таймеров, предыдущих значений или флагов.

#### Пример 1: Управление фокусом DOM-элемента
```tsx
import React, { useRef } from 'react';

export const AutoFocusInput = () => {
  const inputRef = useRef<HTMLInputElement>(null);

  const handleClick = () => {
    inputRef.current?.focus(); // прямой доступ к DOM
  };

  return (
    <div>
      <input ref={inputRef} type="text" />
      <button onClick={handleClick}>Сфокусировать инпут</button>
    </div>
  );
};
```

#### Пример 2: Хранение ID таймера без ререндеров
```tsx
const timerRef = useRef<number | null>(null);

const startTimer = () => {
  timerRef.current = window.setInterval(() => {
    console.log('Работает таймер...');
  }, 1000);
};

const stopTimer = () => {
  if (timerRef.current) {
    clearInterval(timerRef.current);
  }
};
```

### 📖 Раздел 6. Классовые компоненты и методы жизненного цикла

До появления хуков в React 16.8 компоненты с состоянием писались на основе классов ES6. В наследии проектов часто встречаются классовые компоненты.

#### Структура классового компонента
```tsx
import React, { Component } from 'react';

interface Props {
  title: string;
}

interface State {
  count: number;
}

export class CounterClass extends Component<Props, State> {
  constructor(props: Props) {
    super(props);
    // Инициализация состояния в конструкторе
    this.state = {
      count: 0,
    };
  }

  handleIncrement = () => {
    // В классах состояние обновляется ТОЛЬКО через this.setState
    this.setState((prevState) => ({
      count: prevState.count + 1,
    }));
  };

  render() {
    return (
      <div>
        <h2>{this.props.title}</h2>
        <p>Счетчик: {this.state.count}</p>
        <button onClick={this.handleIncrement}>+1</button>
      </div>
    );
  }
}
```

#### Основные методы жизненного цикла классового компонента:
1. `componentDidMount()`: Вызывается сразу после вставки компонента в DOM. Аналог `useEffect(() => {}, [])`.
2. `componentDidUpdate(prevProps, prevState)`: Вызывается после каждого обновления props или state. Аналог `useEffect(() => {}, [props, state])`.
3. `componentWillUnmount()`: Вызывается непосредственно перед удалением компонента из DOM. Аналог функции очистки `return () => {}` в `useEffect`.

```tsx
componentDidMount() {
  console.log('Компонент появился на экране');
}

componentDidUpdate(prevProps: Props, prevState: State) {
  if (prevState.count !== this.state.count) {
    console.log(`Счетчик изменился с ${prevState.count} на ${this.state.count}`);
  }
}

componentWillUnmount() {
  console.log('Компонент будет удален из DOM');
}
```

### 📖 Раздел 7. Кастомные хуки (Custom Hooks)

Кастомный хук — это обычная JavaScript-функция, имя которой начинается с приставки `use` (например, `useLocalStorage`, `useFetch`, `useWindowSize`), и которая внутри себя вызовет другие хуки React (`useState`, `useEffect` и др.).

#### Правила хуков (Rules of Hooks):
1. **Вызывайте хуки только на верхнем уровне**: Не вызывайте хуки внутри циклов `for`, условий `if` или вложенных функций.
2. **Вызывайте хуки только из компонента React или кастомного хука**.

#### Пример кастомного хука `useLocalStorage`:
```tsx
import { useState, useEffect } from 'react';

export function useLocalStorage<T>(key: string, initialValue: T) {
  const [value, setValue] = useState<T>(() => {
    try {
      const item = localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch {
      return initialValue;
    }
  });

  useEffect(() => {
    try {
      localStorage.setItem(key, JSON.stringify(value));
    } catch (error) {
      console.error(error);
    }
  }, [key, value]);

  return [value, setValue] as const;
}
```
